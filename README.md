# Portfolio Risk Analytics

A practical portfolio risk management project demonstrating institutional-style
risk measurement and portfolio analytics.

## Objectives

The project will cover:

- Portfolio return and volatility analysis
- Historical and parametric VaR
- Expected Shortfall
- Drawdown analysis
- Correlation and diversification
- Factor risk decomposition
- Stress testing
- Scenario analysis
- Portfolio risk contribution
- Risk-adjusted performance
- Portfolio optimization

## Tools

- Python
- pandas
- NumPy
- matplotlib
- scipy
- statsmodels
- Jupyter Notebook
